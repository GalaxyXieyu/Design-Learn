# 百度首页设计风格指南

## 1. 概览

本文档基于百度首页（baidu.com）的实际代码分析，提炼出完整的设计系统规范。百度作为中国最大的搜索引擎，其首页设计经历了多次迭代，当前的设计语言体现了现代搜索引擎的简洁、高效与友好的交互理念。

### 1.1 设计理念

百度的设计哲学可以概括为"简洁高效、以用户为中心"。首页以搜索功能为核心，所有设计元素都服务于这一主要目标。视觉层级清晰，用户能够直观地识别并完成搜索操作。色彩系统以蓝色为主色调，传达专业、信任和科技感。整体布局留白充足，避免视觉干扰，让用户专注于搜索本身。

### 1.2 技术栈

百度首页采用了成熟的前端技术方案。在样式方面，使用了内联 CSS 和外部样式表相结合的策略，部分组件采用了较新的 CSS3 特性如 box-shadow、transition 和 transform。布局方面主要依赖绝对定位和传统的盒子模型，搜索建议框等交互组件使用了固定定位和 z-index 层级管理。交互实现基于原生 JavaScript，通过类名切换实现状态管理。

### 1.3 主题机制

百度首页目前采用亮色主题设计，背景以纯白色（#fff）为主，内容区域使用浅灰色（#f5f5f5、#f8f88f）进行区分。页面通过 meta 标签声明了 theme-color 为 #ffffff，与系统状态栏保持一致。虽然当前版本未发现暗色模式的实现，但设计系统中的颜色变量已经考虑了语义化命名，为未来扩展暗色主题预留了空间。

## 3. 配色系统详解

### 3.1 品牌色彩应用

百度首页的蓝色系品牌色是其最具识别度的视觉特征。不同明度和饱和度的蓝色被应用于不同的场景，形成了一套层次分明的品牌色系统。

**主品牌色 `#4E6EF2`** 是一种明亮的中蓝色，RGB 值为 (78, 110, 242)。这个颜色主要用于搜索框获得焦点时的边框颜色，以及部分强调场景。当用户在搜索框中输入内容时，蓝色的边框提供了清晰的视觉反馈，暗示输入框正处于活跃状态。这个颜色符合 WCAG 2.1 标准，在白色背景上的对比度达到 4.5:1 以上，满足可访问性要求。

**交互品牌色 `#315EFB`** 比主品牌色略深一些，用于链接和交互元素的悬停状态。这个颜色被应用于搜索建议中文字的悬停效果，以及反馈区域的链接悬停。设计师选择这个颜色作为悬停态，既保持了与主品牌色的视觉关联，又提供了足够的视觉区分度，让用户明确感知到交互的发生。

**导航品牌色 `#38f`** 是一种更亮的蓝色，RGB 值为 (51, 136, 255)。这个颜色仅用于顶部导航菜单的悬停背景色。选择这个特殊的蓝色可能是因为导航区域需要与主搜索区域形成视觉区分，同时又要保持品牌的整体协调性。

### 3.2 文本颜色层级

文本颜色的设计遵循"重要性优先"的原则，通过不同的灰度值传达信息的层级关系。这种设计既保持了视觉的简洁性，又确保了信息的有效传达。

**主要文字 `#000`** 用于最重要的内容，如 Logo、标题等。在白色背景上，这个颜色的对比度达到 21:1，远超 WCAG AAA 标准（7:1），确保了最佳的可读性。然而，过高的对比度在大量使用时可能会造成视觉疲劳，因此主要文字的使用是有节制的。

**次要文字 `#333`** 是使用最广泛的正文颜色，在可读性和视觉舒适度之间取得了良好的平衡。这个颜色在白色背景上的对比度约为 12.6:1，同样满足 AAA 标准。绝大多数的正文内容、描述文字都使用这个颜色。

**辅助文字 `#626675`** 和 `#9195A3` 用于不太重要的信息，如搜索建议中的次要部分、提示信息等。这些颜色在白色背景上的对比度分别为 5.8:1 和 3.4:1。需要注意的是， `#9195A3` 仅达到 AA 标准（4.5:1），在重要信息中应谨慎使用。

```tsx

function TextColorExample() {

        百度一下，你就知道

      {/* 板块标题 - 高优先级 */}
      <h2 className="text-xl font-semibold text-[#333]">

      </h2>
      
      {/* 正文内容 - 中等优先级 */}
      <p className="text-base text-[#333] leading-relaxed">
        百度是全球领先的中文搜索引擎，致力于让网民更便捷地获取信息。
      </p>
      
      {/* 辅助说明 - 较低优先级 */}
      <p className="text-sm text-[#626675]">
        已为您找到约 10,000,000 个相关结果
      </p>
      
      {/* 提示信息 - 最低优先级 */}
      <p className="text-xs text-[#9195A3]">
        使用百度前必读 © 2025 Baidu
      </p>
    </div>
  );
}
```

### 3.3 背景颜色系统

背景颜色的设计遵循"功能分区"的原则，不同的区域使用不同的背景色来形成视觉上的分隔和层次感。

**纯白背景 `#FFFFFF`** 是整个页面最主要的背景色，用于主要内容区域。白色背景创造了干净、简洁的视觉感受，符合搜索引擎首页"专注核心功能"的设计理念。

**浅灰背景 `#F5F5F6`** 用于搜索建议框的选中状态背景。当用户在搜索建议列表中移动光标时，对应的项会显示这个背景色，既提供了视觉反馈，又不会过于抢眼。类似的浅灰色 `#F0F0F0` 用于普通列表项的悬停状态。

**更浅的背景 `#F8F8F8`** 用于某些特殊的卡片或区域，与主白色背景形成微妙的区分。这种设计在保持整体简洁的同时，也为内容分区提供了视觉线索。
