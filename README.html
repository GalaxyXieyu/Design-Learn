Web 设计提取 × AI 设计规范 × MCP 可查询

让 AI 写出好看的前端界面

Design-Learn 是一套 Web 设计提取与分析系统：一键捕获优秀网站的设计语言（HTML/CSS/资产/设计 token），自动生成设计规范文档，并通过 MCP 让 AI（Claude Code 等）可查询、可复用，从而稳定产出风格一致的 UI。

Chrome Extension VSCode Extension Node.js + SQLite MCP (SSE / stdio) UI/UX Pro Max (内置知识库)
Quick Start 查看 MCP 工具 系统架构

Vibe Coding 的核心痛点

用 AI 写代码很爽，但让 AI 写出“好看、稳定、可复用”的界面很难控制：

  • 风格不一致：每次生成都不一样
  • 缺乏设计感：看起来像“AI 味”
  • 难以复用：优秀网站的设计语言无法迁移
Claude Code / MCP 
> 用 stripe.com 的设计风格写一个定价页面
# AI 会查询你提取的设计库与 styleguide
# 输出风格一致的页面结构、组件与样式

解决什么问题？

把优秀网页的设计语言结构化，再交给 AI 复用，让 UI 质量变得“可控”。

Design → Spec → Code

Design-Learn 的解决方案

  • 一键提取：采集 HTML/CSS/图片/字体，并提取颜色、排版、间距、圆角、阴影等要素
  • AI 分析：生成可读、可复用的设计规范文档（styleguide）
  • MCP 集成：让智能体按需查询设计库与规范，生成风格一致的代码

数据如何沉淀？

既能快速检索，也能保存大体量内容。SQLite 做元数据与索引，文件系统保存快照与大对象。

Storage 
data/
├── database.sqlite        # 元数据与索引
└── designs/               # 设计资源（JSON/快照/组件代码/styleguide）

核心能力

从采集到分析再到生成，形成可组合、可迭代的闭环。

一键提取页面设计

  • 完整快照：HTML + CSS + 图片 + 字体
  • 设计 token：颜色、字体、间距、圆角、阴影
  • 元数据：视口尺寸、元素统计等

AI 智能分析（styleguide）

  • 色彩系统：主色/辅助色/语义色/渐变
  • 字体排版：字号层级、行高、字重、字族
  • 组件规范：按钮、卡片、表单等规则描述

MCP 可查询设计库

  • 按关键词/URL 搜索本地采集 designs
  • 获取最新 styleguide markdown
  • 聚合搜索：本地 designs + 内置 UI/UX Pro 知识库

系统架构

多端协同：Chrome/VSCode/AI 客户端共享同一个本地服务与数据层。

Multi-Client Single-Server 
Chrome Extension ──┐
                   ├──> HTTP API (port 3100)
VSCode Extension ──┤    - /api/health
                   │    - /api/import/*
Claude Code ───────┘    - /mcp (SSE/stdio)
                        - /api/designs
                        - /api/snapshots

                   Design-Learn Server
                   (SQLite + File Storage)

关键路径

  • Browser Extraction：插件采集页面快照 → `/api/import/browser`
  • Pipeline：处理入库 → SQLite + 文件存储
  • MCP Access：智能体调用工具 → 查询 designs / styleguide / UIPro
  • VSCode UI：管理服务生命周期与资源浏览

Playwright 为可选依赖：用于 `/api/import/url` 的服务端抓取（缺失会优雅失败）。

Quick Start

推荐路径：先用 Chrome 插件提取，再按需开启本地服务与 MCP。

1) 安装 Chrome 插件

  • 打开：chrome://extensions/
  • 开启“开发者模式”
  • 加载已解压的扩展程序 → 选择 chrome-extension/

2) 启动本地服务（可选）

服务提供 REST API + MCP（SSE/stdio），默认端口 3100。

Server 
cd design-learn-server
npm install
node src/server.js

3) 配置 MCP（Claude Code）

使用 stdio 模式对接 MCP（适合本地集成）。

MCP stdio 
claude mcp add -s user design-learn -- node /YOUR/PATH/Design-Learn/design-learn-server/src/stdio.js
claude mcp list

4) 验证服务健康

如果端口冲突或 MCP 连接失败，先确认服务可用。

Health 
curl http://localhost:3100/api/health
./scripts/verify-backend.sh

5) VSCode 扩展（可选）

推荐使用 Extension Development Host 调试（不需要频繁打包安装）。

VSCode Extension 
cd vscode-extension
npm install
npm run compile
# 在 VSCode 中打开该目录，按 F5 启动 Extension Development Host

6) URL 导入（Playwright 可选）

用于服务端抓取与入库；未安装 Playwright 会返回 playwright_not_installed。

Import URL 
curl -X POST http://localhost:3100/api/import/url \
  -H 'Content-Type: application/json' \
  -d '{"url":"https://example.com"}'

MCP 工具与资源

工具以 “可组合” 为核心：本地采集库 + 内置 UI/UX Pro 知识库，一次或多次调用均可。

Tools

工具名 用途
list_designs 列出本地已采集 designs（可选 limit）
search_designs 按关键词/URL/标签搜索本地 designs（可选 limit）
get_styleguide 获取 design 最新版本的 styleguide markdown
search_library 聚合搜索：本地 designs + UI/UX Pro（BM25）
list_uipro_domains 列出 UI/UX Pro 的 domain
list_uipro_stacks 列出 UI/UX Pro 的 stack
search_uipro 搜索 UI/UX Pro（BM25），支持 domain?
search_uipro_stack 搜索某个 stack 的指南（BM25），必须传 stack

Resources & Prompts

  • Resource：design-learn://info（服务元信息）
  • Resource：design://{designId}（design 元数据）
  • Prompt：analyze_design（生成 “设计特征摘要/风险点” 的提示）
Example 
# 组合调用建议（AI 侧）
1) search_designs(query)  # 优先命中你的采集库
2) search_uipro(query)    # 用内置知识库补齐设计/UX guideline
3) get_styleguide(designId) # 需要更完整规范时再取

内置知识库：UI/UX Pro Max

除了你采集的网站设计库，Design-Learn 还内置一份可搜索的 UI/UX guideline 数据（CSV + Node BM25）。

Domain（9 类）

用于从不同角度补齐风格描述、配色、排版与 UX 细节。

style prompt color chart landing product ux typography icons

Stack（11 类）

当你需要“技术栈约束 + 风格约束”同时成立时，用 stack 指南更稳。

html-tailwind react nextjs vue nuxtjs nuxt-ui svelte swiftui react-native flutter shadcn

FAQ

遇到问题先看这几条，基本能覆盖 80% 的卡点。

插件未显示 / 无法加载？
确认选择的是 chrome-extension/ 根目录，并已开启浏览器的“开发者模式”。Edge/Brave 也同理。
AI 调用失败？
检查插件内的 API Key、Base URL、Model 配置；若调用链路依赖代理或网关，也需要确认可达性与权限。
better-sqlite3 报错？
在 design-learn-server/ 目录执行 npm rebuild better-sqlite3 重新编译原生模块。
MCP 连接失败？
先确认服务已启动并可访问：curl http://localhost:3100/api/health。如果端口被占用，可通过环境变量 PORT 覆盖。
